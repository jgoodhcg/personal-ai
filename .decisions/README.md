# Decision Records

Use this directory for high-impact or irreversible decisions.

## Required Artifact

- `.decisions/[name].json` using `matrix-reloaded` format.
- The JSON matrix is authoritative.

## Optional Companion

- `.decisions/[name].md` for narrative context (status, context, options, decision, consequences).

## Agent Rule

Do not run `matrix-reloaded` CLI from agent sessions. Use project-provided structure and examples in this repo.
